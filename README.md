# Мысықты үйіне жеткіз — баптау (тегін, ~10 минут)

Бір HTML файл көп құрылғы арасында деректі өзі синхрондай алмайды, сондықтан ортақ сервер ретінде **Firebase Realtime Database** (тегін Spark жоспары) қолданылады.

1. console.firebase.google.com → **Add project** (Analytics қажет емес).
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable.**
3. **Build → Realtime Database → Create database** → Start in locked mode.
4. Database → **Rules** қойындысына `database.rules.json` мазмұнын қойып, **Publish** басыңыз.
5. **Project settings → General → Your apps → Web (</>)** → тіркеңіз. Шыққан `apiKey, authDomain, databaseURL, projectId, appId` мәндерін `index.html` ішіндегі `const FB={...}` нысанына қойыңыз.
6. `index.html` файлын **https** хостингке жүктеңіз (Firebase Hosting, GitHub Pages немесе Netlify Drop). Файлды телефонда тікелей ашуға болмайды.
7. Firebase → Authentication → Settings → **Authorized domains** тізіміне хостинг доменін қосыңыз.

## Ойнау
Ұйымдастырушы «ОЙЫН БӨЛМЕСІН ҚҰРУ» басады (бөлме коды мен QR жоқ, бөлме біреу) → оқушылар сол сілтемені ашып «ОЙЫНҒА ҚОСЫЛУ» арқылы топ пен атын таңдайды → «ОЙЫНДЫ БАСТАУ». Жаңа ойын үшін «ОЙЫН БӨЛМЕСІН ҚҰРУ» қайта басылады (бұрынғы нәтиже өшеді), бірақ сол браузерден болуы керек.

## Ескертпелер
- **Ұйымдастырушы құрылғысы — төреші.** Жауапты тексеріп, ұпай мен қадамды жазатын сол құрылғы, сондықтан ойын кезінде оның беті ашық тұруы керек (жабылса, қайта ашқанда өңделмеген жауаптар өңделеді).
- Ойыншылар тек өз жауабын бір рет жаза алады; ұпай мен қадамды тек ұйымдастырушы жаза алады (rules). Бір жауап екі рет есептелмейді.
- Жауап кілті `index.html` ішінде, сондықтан техникалық білімі бар оқушы бет коды арқылы көре алады. Толық қорғау үшін Cloud Functions (ақылы Blaze жоспары) керек.
- Оқушы құрылғысын ауыстырса, ұйымдастырушы тізімдегі ✕ арқылы орнын босатады.
- 100 сұрақ пен кілт Word құжатынан автоматты көшірілді, өзгертілген жоқ.

## Екі бет
- **host.html** — ұйымдастырушы беті (бөлмені құру, қосылғандар, ойын барысы, аяқтау, жаңа ойын). Тек өзіңіз ашасыз.
- **index.html** — оқушыларға арналған бет, сілтемесін тек оқушыларға жіберіңіз.
Екеуін де бір хостингке жүктеңіз. Бөлмені тек host.html құра алады, сондықтан оқушылар оны жаңылып ашып жібермейді.
